Code for the SQL Editor on Supabase to find top ten users:


SELECT
    u.display_name,
    au.email,
    u.role,
    u.id,
    COUNT(es.id) AS tests_taken
FROM exam_sessions es
JOIN users u
    ON es.user_id = u.id
JOIN auth.users au
    ON u.id = au.id
GROUP BY u.id, u.display_name, au.email
ORDER BY tests_taken DESC
LIMIT 10;
